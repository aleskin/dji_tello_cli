# DJI Tello CLI — руководство пользователя

[English](../README.md) · **Русский** · [Srpski](manual.sr.md) · [Deutsch](manual.de.md) · [Français](manual.fr.md) · [Español](manual.es.md)

`tello` — интерактивная консольная программа для управления дроном DJI / Ryze Tello с компьютера
под Linux: команды, фигуры с фото и видео, миссии из файла, полёт с клавиатуры и геймпада.
В комплекте — симулятор `tello-sim`: всё можно попробовать без дрона.

## 1. Установка

```bash
sudo apt install cmake g++ googletest libavcodec-dev libavformat-dev libavutil-dev libsdl2-dev
make build      # build/tello и build/tello-sim
make test       # проверка: тесты против симулятора
```

Готовые пакеты: `make package` → `build-package/tello_<версия>_amd64.deb` и `.rpm`.

## 2. Попробовать без дрона

```bash
make run-sim    # симулятор на 127.0.0.1:8889 и программа, подключённая к нему
```

Или в двух терминалах:

```bash
make sim                                     # терминал 1: фейковый дрон, печатает каждую команду
./build/tello --host 127.0.0.1 --port 8889   # терминал 2
```

Симулятор отвечает как настоящий дрон, считает высоту, положение и разряд батареи, сам садится
после 15 с тишины и после `streamon` отдаёт тестовую картинку камеры. Перед первым настоящим
полётом прогоните на нём всё, что собираетесь делать.

## 3. Первый полёт

1. Включите дрон и подключитесь к его Wi-Fi (`TELLO-XXXXXX`).
2. Запустите `./build/tello` (для Tello EDU: `./build/tello --model tello-edu`).
3. Наберите `help`.

```
tello> takeoff; up 50; cw 90
tello> battery
tello> land
```

Несколько команд пишутся в одну строку через `;`; строка останавливается на первой ошибке.
`Tab` дополняет команды, стрелки листают историю.

Ключи запуска: `--host`, `--port`, `--state-port` (0 — без телеметрии), `--video-port`,
`--model`, `--mission ФАЙЛ`, `--log-dir ПАПКА`, `--no-log`.

## 4. Безопасность

- **Ctrl+C в воздухе — посадка.** Программа никогда не закрывается с дроном в воздухе.
  На земле Ctrl+C только стирает строку; выход — `exit` или Ctrl+D.
- **Keepalive:** дрон сам садится через 15 с без команд, поэтому программа шлёт ему сигнал, пока вы молчите.
- **Батарея:** предупреждение при 15 %, автоматическая посадка при 10 % (настраивается), повторяется каждые 3 с, пока дрон её не подтвердит.
- **Безопасный выход:** `exit`, Ctrl+D или конец миссии в воздухе сначала сажают дрон и выходят
  только после посадки. Если посадка не прошла, программа остаётся открытой (`land` или `emergency`;
  повторный `exit` выходит всё равно).
- **Аварийная посадка:** если программа падает в воздухе (сбой, `kill`, закрытый терминал), она
  успевает послать `land` и пишет это в журнал. Если команда зависла на 45 с — дрон тоже садится.
- Не покрывается: `kill -9`, севший ноутбук, потеря Wi-Fi — тогда Tello сам садится через 15 с
  без команд.
- **`emergency`** выключает моторы сразу, без подтверждения — дрон падает. Только для крайнего случая.
- Летайте над мягкой поверхностью, вдали от людей и деревьев; первые фигуры — с `dry` (см. ниже).

## 5. Команды

`help` показывает только то, что умеет выбранная модель; `help <команда>` — подробности.

| Группа | Команды |
|---|---|
| Система | `help [cmd]`, `version`, `info`, `wait <с>`, `alias`, `aliases`, `unalias <имя>`, `exit`, `log` (путь к журналу сеанса) |
| Полёт | `connect`, `takeoff`, `land`, `hover` (EDU), `emergency` |
| Движение | `forward/back/left/right/up/down <20..500 см>`, `cw/ccw <1..360°>`, `flip <l\|r\|f\|b>`, `speed <10..100 см/с>`, `go <x> <y> <z> <скорость>`, `return` / `home` (вернуться к точке взлёта и сесть) |
| Камера на точку | `camera_to_center <x> <y>`, `camera_from_center <x> <y>`, `orbit <50..500 см> [cw\|ccw] [скорость]` (облёт точки впереди за 12 отрезков) |
| Миссии | `mission <файл>`, `square <см>`, `record start <файл>\|stop\|status` |
| Клавиатура | `keyboard` / `kb`, `kbspeed [10..100]` |
| Геймпад | `joystick` / `js` |
| Видео и фото | `video start\|stop\|show\|hide\|status`, `photo` |
| Телеметрия | `battery`, `height`, `wifi`, `get_speed`, `temp`, `time`, `attitude`, `baro`, `tof`, `sdk` (EDU), `sn` (EDU), `state`, `position` / `pos` |

У `takeoff` нет высоты: взлёт (около 80 см), потом `up <см>`.

## 6. Фигуры

Фигура — готовый полёт одной командой: взлёт, фигура, возврат в центр, посадка. Все параметры
необязательны и идут по порядку; слова (`cw`, `in`, `flat`...) можно ставить в любом месте.
Единицы: сантиметры, градусы, см/с.

- **`dry`** в конце любой фигуры — ничего не отправлять дрону, а показать список команд, число фото,
  время, максимальную высоту и расход батареи. Например: `flower 300 150 dry`.
- **`video`** — записать видео всего полёта в `~/Videos/tello/`.
- Фото фигуры ложатся в отдельную папку `~/Pictures/tello/<фигура>_ДАТА_ВРЕМЯ/01.jpg, 02.jpg...`
- Перед взлётом программа проверяет, что есть картинка с камеры; без неё не взлетает.
- Если команда в воздухе не прошла — фигура прерывается и дрон садится.

| Фигура | Что делает | По умолчанию |
|---|---|---|
| `flower [высота] [радиус] [шаг] [in\|out] [cw\|ccw] [скорость]` | горизонтальный круг вокруг точки взлёта, фото каждые `шаг` градусов; камера `in` — в центр, `out` — наружу | 200, 100, 30°, in, cw, 30 |
| `wheel [высота] [радиус] [шаг] [cw\|ccw] [in\|out] [скорость]` | вертикальный круг поперёк вашего взгляда (влево-вправо), начинает сверху; `cw` — сначала вправо; высота должна быть больше радиуса | 200, 100, 30°, cw, in |
| `loop [высота] [радиус] [шаг] [away\|toward] [in\|out\|side] [скорость]` | вертикальный круг от вас и обратно (вперёд-назад); камера на вас, вперёд или вбок | 200, 100, 30°, away, in |
| `panorama [высота] [шаг] [cw\|ccw]` | поворот на месте с фото на каждом шаге — круговая панорама | 200, 30° |
| `tower [от] [до] [шаг]` | подъём вертикально с фото на каждой высоте (фасад, дерево) | 100..500 через 50 |
| `dronie [дистанция] [высота] [скорость]` | видео: камера на вас, дрон улетает назад и вверх по диагонали, возвращается | 300, 200 |
| `reveal [дистанция] [высота] [скорость]` | видео: начинает низко (50 см), летит вперёд и вверх — вид «открывается» | 300, 200 |
| `bounce [раз] [размах] [cw\|ccw] [скорость]` | качание вверх-вниз; с `cw`/`ccw` — заодно полный оборот | 3 раза, 100 |
| `flips [l\|r\|f\|b ...]` | серия сальто на 150 см; нужно не меньше 50 % батареи | все четыре |
| `helix [витки] [от выс.] [до выс.] [от рад.] [до рад.] [шаг] [cw\|ccw] [скорость]` | видео: спираль вокруг точки взлёта вверх и наружу, камера в центр | 2 витка, 100..300, 100..200 |
| `boomerang [длина] [ширина] [подъём] [cw\|ccw] [скорость]` | видео: овал вокруг точки взлёта с подъёмом на дальнем конце, камера в центр | 400, 200, 100 |
| `eight [радиус] [высота] [шаг] [flat\|upright] [скорость]` | видео: восьмёрка, горизонтальная (`flat`) или вертикальная (`upright`) | 100, 200, flat |
| `polygon <углов> [радиус] [высота] [flat\|upright] [скорость]` | многоугольник из 3..12 углов в воздухе | 100, 200, flat |
| `star [радиус] [высота] [flat\|upright] [скорость]` | пятиконечная звезда | 100, 200, flat |
| `rings [радиус] [от выс.] [до выс.] [колец] [шаг] [скорость]` | несколько кругов фото на разных высотах, камера в центр, всё в одну папку — для 3D-модели (Meshroom и т.п.) | 150, 100..300, 3 кольца |
| `timelapse [интервал с] [кадров] [высота]` | висит и снимает кадр каждые N секунд; после посадки склеивает кадры в `timelapse.mp4` (10 к/с) | 2 с, 30 кадров, 200 |
| `hyperlapse [дистанция] [кадров] [высота] [скорость]` | медленно летит вперёд с кадрами, возвращается; склеивает в `hyperlapse.mp4` | 500, 20 кадров, 200, 20 |
| `scan [ширина] [от выс.] [до выс.] [шаг] [скорость]` | лицом к стене: ряды фото змейкой (ряд, подъём, ряд обратно) с перекрытием | 300, 100..300, 50 |

Примеры:

```
tello> flower dry                    # посмотреть план
tello> flower 150 200 45 out         # круг радиусом 2 м на 1,5 м, фото наружу каждые 45°
tello> wheel 250 100 ccw video       # колесо против часовой, с видео всего полёта
tello> timelapse 5 60                # 60 кадров каждые 5 с, потом timelapse.mp4
```

## 7. Видео и фото

- `video show` — окно с живой картинкой и экранной информацией (батарея, высота, курс); `video hide` — закрыть.
- `video start` / `video stop` — запись в `~/Videos/tello/tello_ДАТА_ВРЕМЯ.mp4` (без перекодирования).
- `photo` — кадр с камеры в `~/Pictures/tello/`. У Tello нет памяти для фото: снимок берётся из
  видеопотока на компьютере.

## 8. Клавиатура и геймпад

- **`keyboard`** (в воздухе): управление клавишами в окне видео — `W/A/S/D` движение,
  стрелки вверх/вниз — высота, влево/вправо — поворот, `Esc` — назад к командам.
  `kbspeed 60` — сила «стиков» (по умолчанию 40).
- **`joystick`** (и на земле): правый стик — движение, левый — высота и поворот,
  `A` — взлёт, `B` — посадка, `Back`+`Start` вместе — аварийная остановка моторов,
  `Esc` в окне или `Guide` — назад к командам.

## 9. Миссии и запись маршрута

Миссия — текстовый файл, одна строка команд на строку, `#` — комментарий. На первой ошибке миссия
останавливается и дрон садится.

```
# mission.txt
takeoff
up 50
square 100
land
```

```bash
./build/tello --mission mission.txt    # код выхода 0, только если все строки прошли
```

Внутри программы: `mission mission.txt`.

**Запись маршрута:** `record start route.txt` — все команды полёта, движения, фигур и камеры
пишутся в файл до `record stop`. Полёт с клавиатуры или геймпада записывается одной командой `go`
и поворотом по рассчитанному положению. `mission route.txt` повторяет маршрут. `record status` —
сколько строк уже записано.

## 10. Свои команды (алиасы)

```
tello> alias hop up $1; down $1      # $1..$9 — аргументы, $* — все
tello> takeoff; hop 50; land
tello> aliases                       # список; unalias hop — удалить
```

Алиасы сохраняются в `~/.config/tello/aliases` и работают в миссиях.

## 11. Настройки

Файл `~/.config/tello/config`, ключи командной строки важнее его.

```
host = 192.168.10.1
port = 8889
state_port = 8890        # 0 — без телеметрии
video_port = 11111
model = tello            # или tello-edu
warn_battery = 15        # проценты
land_battery = 10
kbspeed = 40             # клавиатура, 10..100
js_deadzone = 10         # геймпад, мёртвая зона стика в процентах, 0..50
log_dir = ~/.local/state/tello/logs   # журналы сеансов; "off" — без журнала
log_keep = 30            # сколько последних журналов хранить
key_forward = w          # и key_back/left/right/up/down/turn_left/turn_right
```

## 12. Журнал полёта

Каждый запуск пишет текстовый журнал для разбора после полёта, один файл на сеанс:
`~/.local/state/tello/logs/tello_ГГГГММДД_ЧЧММСС.log` (или `$XDG_STATE_HOME/tello/logs`),
хранятся 30 последних. Команда `log` показывает текущий файл; `--log-dir ПАПКА` или `log_dir`
меняют место, `--no-log` или `log_dir = off` выключают журнал. Записи пишутся сразу —
при падении программы ничего не теряется.

Что в журнале:
- **заголовок сеанса**: версия, командная строка, модель, адрес и порты, пороги батареи;
- **каждая введённая строка и команда** с `begin` / `end ...: ok|failed: <причина>|exception, N ms` —
  `begin` без `end` значит, что команда зависла или программа упала на ней;
- **каждая команда SDK и ответ дрона** (`> takeoff`, `< ok  [takeoff, 2140 ms]`), таймауты,
  опоздавшие ответы; повторы `rc` считаются, а не пишутся по одному;
- **позиция** после каждой лётной команды, **телеметрия** раз в секунду в воздухе (раз в 10 с
  на земле), `telemetry lost` / `telemetry back`;
- **всё, что было на экране** (`console: ...`), предупреждения о батарее, события видеопотока,
  фото и записи, Ctrl+C, ошибки и непредвиденные исключения, аварийные сигналы (`*** FATAL signal N`).

Строка выглядит так: `2026-11-05 09:24:20.387 INFO  main     drone: > takeoff`
(время, уровень `DEBUG/INFO/WARN/ERROR`, поток, компонент). Найти проблемы:
`grep -E 'WARN|ERROR|FATAL' ~/.local/state/tello/logs/tello_*.log`.

## 13. Что нужно знать о Tello

- **Камера смотрит только вперёд и не наклоняется.** Точка взлёта видна в кадре, только если
  радиус больше примерно двух высот. `loop` пролетает на `радиус` см позади точки взлёта —
  отойдите в сторону или подальше назад.
- **Нет GPS.** Положение считается «по счислению» — из выполненных команд и скорости из телеметрии.
  Ошибка растёт с каждым метром; `return` — это не GPS-возврат домой, а прямые отрезки по этой оценке.
- Короткие перемещения меньше 20 см дрон не выполняет; одна команда — не больше 500 см.
- Сальто — только при заряде больше 50 %.
