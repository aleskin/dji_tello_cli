### 🔧 Build & Infrastructure

### [TEL-00031] build: разобрать замечания make sanity-check
- **Status:** ✅ Выполнена
- **Complexity:** 3
- **Description:** 132 замечания clang-tidy (v0.0.3). Исправить реальные: `bugprone-*`
  (empty-catch с комментарием, throwing-static-init), `performance-*`, `scoped_lock`, `std::array`
  вместо C-массивов. Стилевой шум (designated initializers, unchecked `operator[]` на проверенных
  индексах) — отключить в `.clang-tidy` с причиной. Цель: отчёт без замечаний.

### 🛰️ Core

### [TEL-00020] core: позиция — базовый класс, счисление по командам, return-to-home
- **Status:** Открыта
- **Complexity:** 8
- **Description:** Решение владельца: позиция — отдельная иерархия, как дроны.
  1. База `drone::PositionSource`: текущая позиция (x, y, z от точки взлёта) и курс, точность
     (оценка ошибки), источник; уведомления о командах движения.
  2. `DeadReckoning : PositionSource` — для дронов без спутников (Tello): позиция «в памяти» по
     выполненным командам + интегрирование `vgx/vgy/vgz` из телеметрии.
  3. Спутниковый источник (GPS/ГЛОНАСС) — TEL-00034, коррекция по камере — TEL-00035 (бэклог).
  Модель дрона говорит, какой источник ей доступен (`capabilities`). Поверх базы: `get_position`,
  `return` — обратный путь к точке взлёта. Тест на `tello-sim` (у него есть истинная позиция).
