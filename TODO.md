### 💻 CLI

### [TEL-00040] cli: `dry` — проверка фигуры без взлёта
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `<фигура> ... dry`: ничего не отправляет дрону, печатает команды по порядку, число фото, время полёта, максимальную высоту и примерный расход батареи. Для этого фигуры строят план (точки, повороты, фото, команды) отдельно от полёта; полёт выполняет тот же план.

### [TEL-00041] cli: флаг `video` для фигур
- **Status:** ✅ Выполнена
- **Complexity:** 1
- **Description:** `<фигура> ... video`: на время фигуры включается запись видео (`video start` после проверки картинки, `video stop` после посадки), файл в `~/Videos/tello/`.

### [TEL-00042] cli: фигура `panorama` — круговая панорама на месте
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `panorama [высота] [шаг] [cw|ccw]`, по умолчанию 200 см / 30°: взлёт, подъём, поворот по шагам с фото на каждом, посадка. Склейка — TEL-00027 в бэклоге.

### [TEL-00043] cli: фигура `tower` — фото на разных высотах
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `tower [от] [до] [шаг]`, по умолчанию 100..500 через 50 см: взлёт, подъёмы по шагу с фото на каждой высоте (вертикальная панорама фасада, дерева), спуск, посадка.

### [TEL-00044] cli: фигура `dronie` — отлёт назад и вверх с видео
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `dronie [дистанция] [высота] [скорость]`, по умолчанию 300 / 200 см: камера на пилота, дрон уходит назад и вверх по диагонали, пишет видео, возвращается и садится.

### [TEL-00045] cli: фигура `reveal` — низко и близко, потом вверх и назад
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `reveal [дистанция] [высота] [скорость]`: старт низко лицом от пилота (камера вперёд), подъём с отлётом вперёд — «открытие» вида, видео, возврат, посадка.

### [TEL-00046] cli: фигура `bounce` — качание вверх-вниз
- **Status:** ✅ Выполнена
- **Complexity:** 1
- **Description:** `bounce [раз] [размах] [cw|ccw]`: взлёт, N раз вверх-вниз, по желанию с поворотом, посадка.

### [TEL-00047] cli: фигура `flips` — шоу сальто
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** `flips [l|r|f|b ...]`, по умолчанию все четыре: проверка батареи (Tello делает сальто при заряде > 50%), взлёт, подъём на безопасную высоту, серия сальто с паузами, посадка.

### [TEL-00048] cli: фигура `helix` — спираль вокруг точки
- **Status:** Открыта
- **Complexity:** 3
- **Description:** `helix [витки] [от высоты] [до высоты] [от радиуса] [до радиуса] [шаг] [cw|ccw]`: облёт вокруг точки взлёта с подъёмом и расширением, камера в центр, видео; возврат в центр, посадка.

### [TEL-00049] cli: фигура `boomerang` — овал с подъёмом
- **Status:** Открыта
- **Complexity:** 3
- **Description:** `boomerang [длина] [ширина] [подъём]`: облёт пилота по овалу, на дальнем конце подъём, обратно спуск, камера в центр, видео, посадка.

### [TEL-00050] cli: фигура `eight` — восьмёрка
- **Status:** Открыта
- **Complexity:** 3
- **Description:** `eight [радиус] [высота] [шаг] [flat|upright]`: два круга подряд в разные стороны, горизонтально или вертикально, видео, посадка в центре.

### [TEL-00051] cli: фигура `polygon` / `star` — многоугольник и звезда
- **Status:** Открыта
- **Complexity:** 2
- **Description:** `polygon <N> [радиус] [высота] [flat|upright]`, `star [радиус] [высота] [flat|upright]`: рисует фигуру в воздухе по вершинам, возврат в центр, посадка.

### [TEL-00052] cli: фигура `rings` — кольца для 3D-скана
- **Status:** Открыта
- **Complexity:** 3
- **Description:** `rings [радиус] [от высоты] [до высоты] [колец] [шаг]`: несколько «цветков» на разных высотах, камера в центр, фото в одну папку — для сборки 3D-модели (Meshroom).

### [TEL-00053] cli: `timelapse` / `hyperlapse`
- **Status:** Открыта
- **Complexity:** 3
- **Description:** `timelapse [интервал с] [кадров]` — висит и снимает; `hyperlapse [дистанция] [кадров]` — медленно летит вперёд с фото. Кадры собираются в MP4 через FFmpeg.

### [TEL-00054] cli: фигура `scan` — змейка по стене
- **Status:** Открыта
- **Complexity:** 5
- **Description:** `scan [ширина] [от высоты] [до высоты] [шаг]`: проход стены/фасада рядами (ряд, подъём, ряд обратно), фото с перекрытием, посадка.

### [TEL-00055] cli: запомнить и повторить маршрут
- **Status:** Открыта
- **Complexity:** 5
- **Description:** `record start|stop <файл>`: полёт с клавиатуры/джойстика или командами записывается в файл миссии (относительные шаги по счислению), `mission <файл>` повторяет.

### [TEL-00013] Купить батарею и первый реальный полёт по чек-листу
- **Status:** ❗ Требует действий владельца
- **Complexity:** 2
- **Description:** Батарея заказывается. Первый полёт: открытое место без ветра, `battery?`, `takeoff`,
  `up 50`, `cw 90`, `land`; затем keepalive (постоять 20 с в воздухе) и `emergency` на высоте < 30 см.
  Перед взлётом `tello --model tello-edu`, `sdk` и `sn`: ответ `unknown command` = прошивка SDK 1.3
  (наш `--model tello`), число = SDK 2.0. Результаты — новыми задачами в Sandbox.
