### 🔧 Build & Infrastructure

### 🛰️ Core

### [TEL-00059] BF core: неудачная посадка по батарее не отключает повторные попытки
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** Ревью F02. `FlightGuard::check_battery` ставит `landed_` до `land()`; при ошибке
  посадки повторов не будет до конца разряда. Отметку ставить только после успешной посадки,
  повторять с паузой (не чаще раза в несколько секунд), пока заряд критический и дрон летит.

### [TEL-00060] BF core: keepalive с коротким таймаутом, не блокирует land/emergency
- **Status:** ✅ Выполнена
- **Complexity:** 3
- **Description:** Ревью F04. `keepalive()` ждёт ответ полный action-таймаут (20 с) под мьютексом
  транспорта, и `land`/`emergency` стоят в очереди. Отдельный короткий таймаут keepalive (~1–2 с);
  `emergency` и `land` из CLI сначала шлются `send_now` в обход очереди.

### [TEL-00063] BF core: опоздавший ответ не подтверждает посадку
- **Status:** Открыта
- **Complexity:** 5
- **Description:** Ревью F05. После таймаута команды её поздний `ok` может прийти во время
  `land` и быть принят как ответ на посадку. После таймаута действия считать связь
  рассинхронизированной: посадку подтверждать по телеметрии (высота/`h`), если она есть.

### 💻 CLI

### [TEL-00058] BF cli: потерянный ответ на takeoff — считать дрон «возможно в воздухе»
- **Status:** ✅ Выполнена
- **Complexity:** 3
- **Description:** Ревью F01. Дрон взлетел, `ok` потерялся → `airborne_` остаётся false, и
  Ctrl+C / exit / аварийная посадка / сторож зависания посадку пропускают. Ставить «в воздухе»
  до отправки `takeoff` (при ошибке оставлять); сбрасывать только после успешных `land`/`emergency`.

### [TEL-00061] BF cli: SIGPIPE не убивает программу без аварийной посадки
- **Status:** ✅ Выполнена
- **Complexity:** 2
- **Description:** Ревью F06. Вывод в pipe, читатель закрылся → SIGPIPE убивает процесс без
  `emergency_land()`. Игнорировать SIGPIPE; при ошибке записи в консоль — в воздухе посадить и выйти.

### [TEL-00062] BF video: запись на диск не держит блокировку кадра; ручное управление гаснет при зависании окна
- **Status:** Открыта
- **Complexity:** 8
- **Description:** Ревью F03. `av_interleaved_write_frame` идёт под `VideoStream::mutex_`; зависший
  диск блокирует окно, оно не видит отпускание клавиш, а CLI шлёт старый `rc` каждые 50 мс.
  Запись вне блокировки кадра; у ввода окна метка свежести — устарел → `rc 0 0 0 0`.

### [TEL-00013] Купить батарею и первый реальный полёт по чек-листу
- **Status:** ❗ Требует действий владельца
- **Complexity:** 2
- **Description:** Батарея заказывается. Первый полёт: открытое место без ветра, `battery?`, `takeoff`,
